# 军事地图是怎么画的（白话调研版）

> 一句话：**正规军事地图 = 地形图打底 + 部队要素叠加**。地形是主角，部队和箭头是叠在地形上的第二层。
> 本文回答三个问题：正规军图上画什么、怎么画、我们缺什么。所有结论都有出处（文末清单）。

---

## 一、地形标注（军图的主角）

正规军事地图的地形底子就是**等高线地形图**——指挥官选阵地、定行军路线，全靠看地形。西点军校图集编绘规范（Army History 2024 期刊原文）说得很直白：**地形只画「影响军事判断」的，其他全省略**。

| 地形要素 | 军图上怎么画 | 为什么标 | 我们缺不缺 |
|---|---|---|---|
| **等高线 + 高程点** | 一圈圈闭合曲线，山顶标海拔数字 | 看坡度（坦克爬不爬得动）、看通视（炮打不打得到） | 底图有地形晕渲，**没有等高线/高程** |
| **山与隘口（山口）** | 山名 + 隘口画出通道 | 西点规范原话：**「山口因关系行军，必须画出」**——隘口是部队唯一能过的地方 | **缺**。腊子口是绝壁隘口，图上看不出 |
| **河流** | 蓝线，**只画影响行军或能当防御阵地的**，其他省略 | 河是天然防线 | 有河流底图，**没有「防御性河流」语义标注** |
| **渡口 / 桥梁** | 标在河上，有的还标载重等级 | 全军过河的咽喉（泸定桥就是一座桥） | **缺**。金沙江皎平渡、大渡河安顺场都只活在文字里 |
| **沼泽 / 湿地** | 蓝色斜纹填充 | 装甲和炮兵的天敌（黄泛区困住机械化部队） | **缺**。长征「草地」画成普通山地色 |
| **森林** | 绿色填充 | 隐蔽、遮蔽、薪柴 | 缺 |
| **道路 / 铁路** | 线 + 等级（主要公路/小路/铁路双线） | 有趣的是：**经典战役图上道路反而常删**（葛底斯堡系列图就没画路），只画影响行军的 | 有交通线层，但战役层不区分「影响行军的」 |
| **城镇村庄** | 大小分级（城市/镇/村） | 防御的依托、补给的节点 | 有居民地层 ✓ |

**为什么地形是主角**：拿长征对照一眼就懂——巧渡金沙江是「渡口」，飞夺泸定桥是「桥」，翻夹金山是「雪山」，过草地是「沼泽」，打腊子口是「隘口」。**长征每一步都是地形决定的**。正规军史地图集会把这五样画在图上，部队箭头叠在上面，读者一眼就看懂「为什么非走这条路线」。

## 二、部队怎么画（军标 = 部队的"文字"）

正规军图不用画小人——部队是一个**带番号的框**，这套符号体系叫「军标」。

| 元素 | 军图上怎么画 | 我们缺不缺 |
|---|---|---|
| **部队框** | 一个矩形框，框里画兵种符号（步兵=交叉斜线，装甲=椭圆，炮兵=实心圆点） | **缺**（现在只有菱形+名签） |
| **编制级别记号** | 框上方的叉叉：军=XXX、师=XX、旅=X、团=III、营=II（III 就是三根竖杠=团） | **缺** |
| **番号** | 直接印在框里或框旁：「第7军」「整编第74师」 | 名签里有战役名，**没有部队番号框** |
| **颜色** | 中国军标：**我军红、敌军蓝**（与北约相反！北约是己蓝敌红）；国民党旧制是「我蓝敌红」 | 我们 pla 红 / kmt 蓝——**天然符合中式惯例 ✓** |
| **指挥所** | 框加一面小旗，从框引出一条折线指到实际位置 | **缺** |
| **兵力数字** | 标在框下方（数量 1 不标、概略量加 +/−） | 兵力条在卡片里，图上没有 |

> 中国军标颜色出处：参谋业务规范「我军队标红色、队号黑色；敌军队标队号均蓝色」——与北约相反，这是做中文军图最容易踩的坑（我们刚好没踩）。

## 三、战线怎么画（叙事的骨架）

| 画法 | 说明 | 我们缺不缺 |
|---|---|---|
| **带日期的多条前线线** | 同一张图画两条前线线，各标日期（如「前线，6月22日」「前线，10月初」）——两条线之间夹出的地盘就是这段时间的战果。图例里给每条线一个色样。**这是军史图集叙事的骨架** | **缺**（我们只有半透明色块，没有「线」） |
| **FLOT 连续前线线** | 现代标准（ISW 乌战图）：一条连续实线表示己方最前沿，混杂地带用「灰区多边形」单独标注 | **缺** |
| **锯齿状前线** | 网上常见的「带牙齿」前线——**查证结果：不是军规符号**，是民间 OSINT 地图的习惯画法。正规机构不用 | 不建议抄 |
| **态势日期戳** | 图题就是日期快照：西点图集每张图标题写「Situation 30 June 1863」；现代图写「数据截止 5 月 31 日」 | **缺**（日期在卡片里，图上没有戳） |

## 四、箭头怎么画（会说话的箭头）

| 箭头 | 军图怎么画 | 我们缺不缺 |
|---|---|---|
| **主攻箭头** | 粗实线箭头，军标里有专门的「进攻轴线」符号，还分主攻/助攻两种 | **缺语义**（只有粗细随兵力） |
| **佯攻箭头** | 同一箭头画成**虚线**（条令原文规定 Feint 用虚线） | **缺**（我们 claimed 虚线语义已移到兵力条斜纹） |
| **退却线** | 细线/带叉 | **缺** |
| **箭头长度** | Minard 传统：**宽度或长度可以编码兵力**（1mm=1万人）；西点新式图让箭长≈行军纵队实际里程（一个军行军占路 7-9 英里） | 我们的 tier 粗细（万/五万/二十万分档）**已经是这个传统的简化版 ✓** |
| **箭头走向** | 弧线贴合道路/河谷，不画直线 | 我们的贝塞尔弧线 ✓ |

## 五、图例、日期戳、诚信标注

| 元素 | 惯例 | 我们缺不缺 |
|---|---|---|
| **图例** | 放图底，列出色块、线型、箭头、兵种符号的含义——**没有图例的军图不算正规军图** | **缺**（阵营色只在卡片里，兵力四档/菱形/箭头语义全无解释） |
| **日期戳** | 图上印「态势日期」（现代图还标「数据截止时间」） | **缺** |
| **诚信机制** | 现代标准（ISW）：控制区只画「可验证、可归因」的证据，图上分「已核实/评估推测」两级，并写免责声明 | **有底子**：我们的 quality 分档（recorded/claimed/est）+ 出处署名与 ISW 的证据分级完全同构 ✓ |

## 六、对照总表：我们缺什么

| 元素 | 正规军图 | 我们现在 | 结论 |
|---|---|---|---|
| 地形标注 | 等高线、隘口、渡口、沼泽（按军事意义取舍） | 有地形晕渲底图 | **缺「军事地形标注层」** |
| 部队符号 | 军标框（框+兵种+级别+番号） | 菱形+名签 | **缺军标式单位框** |
| 战线 | 带日期的前线线 | 半透明色块 | **缺 FLOT 线** |
| 箭头 | 主攻/佯攻/退却 分型 | 粗细随兵力 | **缺语义分型** |
| 图例 | 图底必备 | 无 | **缺图例面板** |
| 阵营配色 | 中式：我红敌蓝 | pla 红 / kmt 蓝 | 天然符合 ✓ |
| 兵力编码 | 宽度/长度编码 | 四档粗细+兵力条 | 已是简化版 ✓ |
| 诚信标注 | 证据分级+出处 | quality 分档+出处 | 已达标 ✓ |

## 七、升级路线（三条，可组合）

### 路线 A：简化中式军标（推荐先做）
自绘 SVG 单位框：矩形框 + 兵种符号（步兵斜线/炮兵圆点，两三种够用）+ 编制级别记号（XXX/XX/X/III）+ 番号文字。我红敌蓝沿用现配色。**不引第三方库**（几十行 SVG 生成代码），视觉立刻「像军图」。
工作量：约 1-2 天（符号生成器 + war-node 替换 + 番号数据补齐 + 图例）。

### 路线 B：完整军标（可选，不急）
vendor 进 milsymbol 库（MIT 协议、零依赖、gzip 约 192KB，懒加载可接受），生成 100% 标准 APP-6 符号，支持中文番号文本。效果最"国际范"，但中文军史语境下 A 已够用，B 是锦上添花。

### 路线 C：图集路线（推荐与 A 组合）
1. **军事地形标注层**：每个战役挑 3-6 个关键地形（隘口/渡口/沼泽/雪山），画符号+名称，带「军事含义」一句话——长征线试点最优（素材现成）
2. **FLOT 前线线**：zone 加 `kind:'front'` 类型（画线不画填充），线旁标日期——战线帧已经是 7 帧，从「面」升级为「线」
3. **箭头语义**：move 加 `axis:'main'|'supporting'|'feint'|'retreat'` 字段 → 粗实线/细线/虚线/退却叉线；数据回填先做近现代六场
4. **图例面板**：挂在沙盘图层里（主图例 #map-key 有现成的「走廊图例」模式可复制），列军标符号含义
5. **态势日期戳**：沙盘激活时图上印「态势 · 1938年10月」式戳

### 实施顺序建议
**长征线做地形标注试点**（素材现成、效果最直观）→ 近现代六场补齐（军标框+前线线+箭头语义+图例）→ 全部 28 场回刷。
